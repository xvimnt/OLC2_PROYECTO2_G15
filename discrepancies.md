# Discrepancies with the VLangCherry grammar

## Declaration with :=

```
mut x = 5
mut x := 5
```

## Array declaration

```
mut arr := []int{1, 2, 3}
```

## Strings inside Strings

```
println("Hello, World!")
```

## Funciones declaradas con fn y no con func

```
fn main() {
	println("Hello, World!")
}
```
